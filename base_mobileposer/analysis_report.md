## 四、方法级别分析

### PNP（6传感器，物理优化）

- Lumbar5 全程稳定在 **20°** 附近，是所有方法中最差的旋转精度
- 翻译漂移中等（120s 约 3.4m）
- 理论上传感器最多、信息最完整，但物理优化对 AMASS 数据的适配可能存在问题（AMASS 合成 IMU 与真实 IMU 存在域差异，PNP 调参针对真实场景）
- UpperArm / Forearm 误差（23°/33°）是唯一小于 MobilePoser 和 IMUCoCo 的区段

### MobilePoser（1–2传感器，神经网络）

- Lumbar5 稳定在 **11.4–12.5°**，全程最一致的神经网络方案
- 2传感器（lw_rp / rw_lp）始终优于1传感器（lp / rp）
- **平移漂移严重**：120s 时 5.4–7.5m，远超 IMUCoCo 和 PNP；单传感器（lp）漂移相对最小（5.4m）
- 各 combo 腰椎误差差异极小（约 0.4° 范围），说明模型对不同传感器配置鲁棒性好

### IMUCoCo（1–6传感器，神经网络）

- 短时（30–60s）Lumbar5 约 13–14°，**弱于 MobilePoser**
- 长时（120s）收敛到 12.5–13.1°，**接近甚至超越 MobilePoser**：说明模型具有长时稳定性
- **6传感器 combo（6s）反而更差**（15.4°@120s），说明 IMUCoCo 在全传感器配置下并非最优，可能是训练/推理策略问题
- UpperArm 误差异常高（44–65°），尤其在带腕部传感器的 combo 中；单髋传感器（lp/rp）UpperArm 误差反而合理（27–32°）
- **平移漂移最小**（120s 约 3.0–3.8m），是有平移输出方法中的最优

### SlimeVR（1–2传感器，纯FK，无学习）

- Lumbar5 全程 **10.1–11.9°**，是所有配置中**最低的旋转误差**
- 关键解释：SlimeVR 直接将髋部 IMU 旋转赋给骨盆及相邻脊椎关节，FK 传播本身在髋-脊区域与真值高度吻合；这正是 Lumbar5 测量的关节组
- **代价**：Knee（30–34°）、UpperArm（45–51°）、Forearm（42–62°）误差极高；无平移输出
- lp 系 combo（含左髋传感器）在 Lumbar5 上稍优于 rp 系

## 六、结论与建议

### 核心结论

1. **SlimeVR（FK）在 Lumbar5 上最优**，但这是其方法特性决定的——直接传播髋部 IMU 到腰椎区域，并非真正"重建"姿态，且缺失平移和全身四肢质量。

2. **MobilePoser 是旋转精度最稳定的神经网络方法**（Lumbar5 约 12°），但平移漂移严重（120s > 6m），对需要跟踪位移的康复场景不适用。

3. **IMUCoCo 是有平移输出方法中的最佳选择**：Lumbar5 120s 约 12.5°，平移漂移最小（约 3m），长时性能还略有改善趋势。

4. **PNP 在 AMASS 合成数据上表现异常差**（约 20°），其设计针对真实 IMU 场景，在合成数据上域差异显著。

5. **传感器数量不一定越多越好**：IMUCoCo 的 6 传感器 combo 比其 1–2 传感器 combo 误差更高，需要进一步排查。

### 对 Route C 的参考价值

- 目标是用模板先验辅助稀疏 IMU（3–6 个）重建康复动作，首要关注腰椎区域
- 基线参考：**MobilePoser 2传感器 ≈ 12°，IMUCoCo 2传感器 ≈ 12.5°**
- FK 天花板：**SlimeVR ≈ 10.6°**（理论下界，因为直接使用传感器旋转）
- Route C 的目标：在稀疏传感器（3–4个）下，Lumbar5 达到 MobilePoser 量级（≈12°）或更优，同时控制平移漂移在 IMUCoCo 量级（≈3m/120s）
